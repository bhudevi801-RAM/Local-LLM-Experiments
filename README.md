# Local LLM Experiments

This repository contains my beginner experiments with local large language models, Python, binary representation, and Ollama.

## Experiments

### 01 — Ollama Setup
Installing Ollama and running a local language model.

### 02 — Binary and ASCII
Understanding how computers represent text using binary and ASCII.

### 03 — Binary Arithmetic
Practising binary addition, subtraction, and other operations.

### 04 — LLM vs Python
Comparing rule-based Python programs with large language model responses.

## Tools Used

- Python
- Ollama
- Visual Studio Code
- GitHub
